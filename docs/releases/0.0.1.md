# Medusa Mega Menu 0.0.1

Initial package for headless navigation built from native Medusa catalog records.

- Manage menus, ordered category/collection sections, selected products and optional image tiles through the Admin extension.
- Resolve published menus through the Store API using the native publishable key's sales channels and current product publication/membership.
- Provide public TypeScript contracts and optional persisted staff RBAC checks without bundling a storefront renderer or duplicating catalog data.

Prepared archives include compiled server/Admin exports, API routes, the native migration and schema snapshot. Shared release preparation verifies the actual package and attaches checksums and provenance. This file supplies notes for future authorized preparation; it does not create or publish a release.
